# 기억을 맞추는 테트리스 — 게임 기획안

## 1. 게임 소개

알츠하이머로 삶의 일부를 잊어버린 주인공이 **어린 시절부터 자신의 인생을 다시 돌아보며, 가족과 함께한 기억을 찾아가는 콘솔 테트리스 게임**이다.

게임을 시작할 때 주인공이 기억을 잃었다는 사실을 알려준다. 플레이어는 어린 시절 → 진학과 취업 → 결혼과 출산 순서로 주인공의 삶을 따라간다. 스테이지마다 **4조각으로 나뉜 가족사진 한 장**이 있고, 줄을 지워 조각을 모두 채우면 그 사진이 앨범에 들어간다. 스테이지를 넘길 때마다 앨범이 한 장씩 채워지고, 마지막에 주인공이 완성된 앨범을 보며 가족을 알아본다.

> **프롤로그 자막 예시**
> 
> 
> “아버지는 가끔 앨범을 펼쳐 놓고 같은 사진을 오래 바라보십니다.”
> 
> “어느 날, 어린아이의 사진을 가리키며 물으셨어요. ‘이 아이는 누구니?’”
> 
> “아버지의 가장 오래된 기억부터, 한 장씩 다시 찾아봅시다.”
> 

## 2. 게임 구성 요약

| 요소 | 개수 | 내용 |
| --- | --- | --- |
| 스테이지 | 3개 | 스테이지마다 가족사진 1장(4분할)을 채운다. 다 채우면 사진이 앨범에 들어가고 다음 스테이지로 넘어간다. |
| 사진 조각 | 스테이지당 4개 | 조각을 하나 채울 때마다 블록 낙하 속도가 빨라진다. |
| 보스 | 3개 (스테이지당 1개) | 사진이 절반(2/4) 채워지면 등장하고, 사진이 완성되면 사라진다. |
| 약 | 2종 | 플레이어에게 이득이 되는 아이템. 속도 감소 약, 맨 아래 한 줄 삭제 약. |

## 3. 공통 플레이 규칙

| 항목 | 규칙 |
| --- | --- |
| 기본 플레이 | 7종 테트로미노를 움직이고 회전시켜 가로줄을 완성한다. |
| 사진 조각 채우기 | 한 스테이지에서 누적 **3줄을 지울 때마다 사진 조각 1개**가 채워진다. 여러 줄을 한 번에 지워도 모두 누적한다. (필요 줄 수는 테스트 후 조정) |
| 조각 연출 | 지운 줄의 블록이 오른쪽 사진 틀로 날아가, 비어 있던 4분할 중 한 칸에 사진 조각이 나타난다. |
| 속도 증가 | **사진 조각을 하나 채울 때마다** 블록 낙하 속도가 한 단계 빨라진다. |
| 보스 등장 | **사진이 절반(2/4) 채워지면** 해당 스테이지의 보스가 등장해 방해 기믹을 사용한다. |
| 스테이지 클리어 | 마지막 조각을 채워 **사진 4/4**가 되면 보스가 사라지고, 완성된 사진이 앨범에 들어가는 연출 후 다음 스테이지로 넘어간다. |
| 다음 스테이지 | 보드를 비우고 새 사진 틀(빈 4분할)로 시작한다. 줄 삭제 누적치와 조각 수는 새 스테이지 기준으로 계산한다. 낙하 속도는 스테이지 시작 속도로 되돌린다. |
| 약 | 게임 중 약을 얻어 원하는 시점에 사용할 수 있다. 자세한 내용은 6장 참고. |
| 실패 및 재시작 | 새 블록을 놓을 공간이 없으면 실패한다. `이 시기의 기억을 다시 찾아볼까요?`를 표시하고, 재도전 시 해당 스테이지의 보드·사진 조각·속도·보스·약 상태를 스테이지 시작 시점으로 되돌린다. |

### 사진 진행 단계

| 사진 진행 | 일어나는 일 |
| --- | --- |
| 0/4 | 스테이지 시작. 빈 사진 틀이 표시된다. |
| 1/4 | 첫 조각이 채워진다. 낙하 속도 1단계 증가. |
| 2/4 | 두 번째 조각이 채워진다. 낙하 속도 2단계 증가. **보스 등장** |
| 3/4 | 세 번째 조각이 채워진다. 낙하 속도 3단계 증가. |
| 4/4 | 사진 완성. 보스 퇴장 → **사진이 앨범에 들어가는 연출** → 다음 스테이지 |

## 4. 스테이지별 구성

### STAGE 1 — 어린 시절

- **블록 테마** · 장난감, 크레파스, 그림책, 교과서
- **완성 사진** · 어린 주인공과 부모님이 함께 찍은 가족사진
- **보스** · STAGE 1 보스 (5장 참고)

| 조각 | 사진에 드러나는 부분 (예시) |
| --- | --- |
| 1/4 | 어린 주인공의 얼굴 |
| 2/4 | 아이를 안고 있는 어머니 |
| 3/4 | 옆에 선 아버지 |
| 4/4 | 배경(집 앞 마당) — **앨범 첫 장 완성** |

### STAGE 2 — 진학과 취업

- **블록 테마** · 교과서, 참고서, 학사모, 이력서, 넥타이
- **완성 사진** · 졸업식 또는 첫 출근 날 부모님과 함께 찍은 가족사진
- **보스** · STAGE 2 보스 (5장 참고)

| 조각 | 사진에 드러나는 부분 (예시) |
| --- | --- |
| 1/4 | 학사모(또는 사원증)를 한 주인공 |
| 2/4 | 꽃다발을 든 어머니 |
| 3/4 | 어깨에 손을 올린 아버지 |
| 4/4 | 배경(학교 정문 또는 회사 건물) — **앨범 두 번째 장 완성** |

### STAGE 3 — 결혼과 출산

- **블록 테마** · 꽃다발, 반지, 턱시도, 집 열쇠, 아기 신발
- **완성 사진** · 주인공과 배우자가 갓 태어난 아이를 안고 찍은 가족사진
- **보스** · STAGE 3 보스 (5장 참고)

| 조각 | 사진에 드러나는 부분 (예시) |
| --- | --- |
| 1/4 | 주인공 |
| 2/4 | 배우자 |
| 3/4 | 두 사람 품에 안긴 아기 |
| 4/4 | 배경(함께 사는 집) — **앨범 세 번째 장 완성** |

## 5. 보스 및 방해 기믹

보스는 주인공이 **기억을 유지하거나, 방금 한 일을 떠올리거나, 다음 동작을 이어가는 데 겪는 어려움**을 게임 규칙으로 표현한다. 모든 스테이지에서 **사진이 절반(2/4) 채워지면 보스가 등장**하고, 사진이 완성(4/4)되면 사라진다.

### 스테이지별 확정란

| 스테이지 | 보스 이름 | 표현할 증상 | 등장 조건 | 기믹 효과 | 발동 주기·지속 시간 | 화면 연출 |
| --- | --- | --- | --- | --- | --- | --- |
| STAGE 1 |  | 단기기억상실 | 사진 2/4 | 보드 일부가 암전돼서 블록이 가려진다. |  |  |
| STAGE 2 |  |  | 사진 2/4 | 내려오던 블록이 다른 모양으로 갑자기 바뀐다. |  |  |
| STAGE 3 |  | 까먹음 | 사진 2/4 | 채워진 블록 중 특정 몇 개를 삭제시킨다. |  |  |

### 기믹 후보

| 후보 | 플레이 규칙 | 연출·논의할 점 |
| --- | --- | --- |
| **시간이 지나면 사라지는 블록** | 일부 블록에 남은 턴 수가 붙는다. 바닥에 고정된 뒤 정해진 턴 안에 줄을 완성하지 못하면 표시된 칸이 사라진다. | 만료 직전 해당 칸을 깜빡이게 한다. 새 테트로미노 하나가 고정될 때마다 1턴이 지나가는 방식으로 계산할 수 있다. |
| **보드 상단 블록 무작위 삭제** | 보드 위쪽에 쌓인 블록 중 일부가 일정 주기마다 무작위로 사라진다. | 방금 쌓은 기억이 사라지는 느낌을 준다. 블록이 사라져 쌓인 높이가 낮아질 수도 있으므로, 한 번에 지우는 칸 수와 대상 범위를 테스트한다. |
| **회전 제한** | 블록당 회전 횟수 제한, 회전 불가 블록 혼합, 스테이지 전체 회전 횟수 제한 중 한 방식을 적용할 수 있다. | 초반에는 자유롭게 회전하고, 이후 제약을 늘리는 방식도 후보로 둔다. 제한을 적용할 경우 남은 횟수나 회전 불가 여부를 블록이 떨어질 때 보여준다. |
| **사라진 자리에 남는 장애물 칸** | 턴이 만료된 블록 일부가 장애물 칸으로 바뀐다. | 회복되지 않은 기억을 표현하는 고난도 변형이다. 장애물 칸이 있는 줄을 지울 수 있는지, 장애물이 얼마나 쌓일 수 있는지 함께 정해야 한다. |

## 6. 약 (플레이어 보조 아이템)

약은 플레이어에게 이득이 되는 아이템으로, 2종류가 있다. 이름은 가칭이며 확정 전이다.

| 약 (가칭) | 효과 | 정할 것 |
| --- | --- | --- |
| **파란 약** | 블록 낙하 속도를 일정 시간 동안 느리게 한다. | 감소 폭, 지속 시간, 효과 중 다시 쓸 수 있는지 |
| **빨간 약** | 보드 맨 아래 한 줄을 즉시 없앤다. | 없앤 줄을 사진 조각 누적 줄 수에 포함할지 |

### 공통 규칙 (논의 필요)

| 항목 | 후보 |
| --- | --- |
| 획득 방식 | ① 일정 확률로 약 표시가 붙은 블록이 내려오고, 그 칸이 포함된 줄을 지우면 획득 ② 보스 등장 시 1개 지급 ③ 사진 조각을 채울 때마다 지급 |
| 보유 한도 | 종류별 1개 / 합쳐서 2개 등 |
| 사용 키 | 약마다 키 하나씩 배정 (예: `1`, `2`) |
| 스테이지 이월 | 다음 스테이지로 넘길지, 스테이지마다 초기화할지 |
| HUD 표시 | 보유 개수, 파란 약 남은 지속 시간 |

## 7. 사진 앨범과 엔딩

### 스테이지 클리어 연출 — 사진이 앨범에 들어가기

1. 마지막 조각이 채워지면 오른쪽의 4분할 경계선이 사라지며 사진 한 장으로 합쳐진다.
2. 보스가 사라지고 보드 진행이 멈춘다.
3. 화면이 앨범으로 전환되고, 완성된 사진이 날아가 앨범의 빈 칸에 붙는다. 이전 스테이지에서 모은 사진도 함께 보여, 앨범이 채워지는 과정이 드러난다.
4. 사진 아래에 짧은 문장을 표시한 뒤 다음 스테이지로 넘어간다.

| 앨범 | 사진 | 사진 아래 문구 예시 |
| --- | --- | --- |
| 1장 | 어린 시절 가족사진 | “엄마 품이 좋아서, 사진을 찍는 내내 내려오지 않으려 했다.” |
| 2장 | 졸업·첫 출근 가족사진 | “첫 출근 날, 집을 나서기 전에 사원증을 세 번이나 확인했다.” |
| 3장 | 아이가 태어난 날의 가족사진 | “처음 너를 안았을 때, 너무 작아서 어떻게 안아야 할지 몰랐다.” |

### 최종 이벤트 — 앨범을 펼치는 날

1. 현재의 주인공이 완성된 앨범을 펼친다. 플레이어가 모은 가족사진 세 장이 순서대로 화면에 나타난다.
2. 마지막 가족사진이 테트로미노 모양으로 흩어졌다가, 조각이 하나씩 떨어지며 다시 맞춰진다. 이 장면은 자동으로 진행된다.
3. 사진 속 아기의 모습이 어린이 → 학생 → 어른으로 이어지고, 현재의 자녀가 주인공 옆에 앉는다.
4. 주인공이 사진과 자녀의 얼굴을 번갈아 보다가 사진 속 순간을 떠올린다.

> **자녀** “이날 기억나요, 아버지?”
> 
> 
> **주인공** “응. 네가 너무 작아서, 어떻게 안아야 할지 몰랐지.”
> 
> 주인공이 자녀의 이름을 부르고, 화면이 가족사진에 멈추며 게임이 끝난다.
> 

## 8. 콘솔 UI 및 역할 분배

콘솔 왼쪽에는 **테트리스 보드**, 오른쪽에는 **4분할 사진 틀·사진 진행(n/4)·현재 속도 단계·보유한 약**을 표시한다. 보스가 등장하면 방해 효과의 발동 여부와 필요한 정보를 HUD에 표시한다. 사진 앨범과 엔딩은 화면을 전환해 보여준다. Windows Terminal 사용을 우선 검토하며, 사진 틀과 배경의 구체적인 배치는 UI 담당자와 협의한다.

| 역할 | 담당 범위 |
| --- | --- |
| **A. 테트리스 코어** | 블록, 보드, 충돌, 회전, 줄 삭제, 보스 기믹·약에 필요한 보드 변경 기능(블록 가리기, 모양 바꾸기, 칸 삭제, 맨 아래 줄 삭제) |
| **B. 화면·입력** | 콘솔 렌더링, 키 입력(약 사용 키 포함), 4분할 사진 틀과 사진 그림, HUD, 깜빡임·조각 이동 연출 |
| **C. 스테이지·사진·보스·약** | 사진 조각 진행, 조각별 속도 증가, 보스 등장 조건(2/4)과 효과, 약 획득·사용·효과 시간 |
| **D. 연출·게임 흐름·통합** | 프롤로그, 스테이지 전환과 재시작, 사진이 앨범에 들어가는 연출, 엔딩, 게임 루프 |

## 9. 미정 사항

- 사진 조각 1개당 필요한 줄 수 (현재 3줄 가정)
- 조각마다 빨라지는 속도 폭, 스테이지 시작 속도
- 보스 이름, STAGE 2 표현 증상, 보스별 발동 주기·지속 시간·화면 연출
- 약 이름(빨간 약·파란 약은 가칭), 획득 방식, 보유 한도, 효과 수치
